# Security policy

## Supported version

Security fixes are provided for the latest published release of Solstice.

| Version | Supported |
|---|---|
| 1.10 | Yes |
| Earlier releases | No |

## Report a vulnerability

Please do not publish security vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option in the Security tab of this repository. Include the affected version, macOS version, reproduction steps, impact, and any relevant logs with personal information removed.

The project does not request passwords, accessibility access, screen recording access, or administrator privileges. Approximate IP-based city detection is optional and disclosed before use.
