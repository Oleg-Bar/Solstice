# Solstice support

For installation questions, rendering problems, or feature requests, open a [GitHub issue](https://github.com/Oleg-Bar/Solstice/issues/new).

Please include:

- Solstice version
- Mac model and processor
- macOS version
- Display resolution and number of displays
- Exact steps that reproduce the problem
- A screenshot when it does not expose private information

Before reporting a screen saver that does not start, confirm that Solstice is selected in **System Settings → Wallpaper → Screen Saver** and check the idle delay under **Lock Screen**.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
