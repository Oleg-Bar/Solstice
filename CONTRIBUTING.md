# Contributing to Solstice

Thank you for helping improve Solstice.

1. Open an issue before a substantial behavior or design change.
2. Keep changes focused and preserve native macOS behavior.
3. Do not add analytics, advertising, accounts, background agents, or undisclosed network access.
4. Preserve attribution and licensing for all third-party code and visual assets.
5. Run the test and build checks before opening a pull request:

```bash
bash Scripts/test.sh
bash Scripts/build.sh
```

Pull requests should explain the user-visible result, macOS and hardware used for testing, and any remaining limitations. Include screenshots for visual changes.
